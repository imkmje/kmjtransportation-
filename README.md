# 교통 시뮬레이션 게임

도로를 깔고, 건물을 놓으면 사람들이 시간표대로 출퇴근하고, 막히는 곳을 찾아 고치는 개인용 3D 교통 시뮬레이션 게임입니다. (Cities: Skylines에서 교통 부분만 가져온 것)

- 현재 버전: **1.0.0**
- 설계: `docs/design.md`, 규칙과 수치: `docs/rules.md`, 진행 기록: `docs/progress.md`, 변경 이력: `CHANGELOG.md`

## 시작하기

1. 시작하면 외부에서 들어오는 도로 하나만 있는 **새 도시**입니다. 도로 옆 땅에 **주거 구역 / 직장 구역**을 칠하면 건물이 자라고 출퇴근이 시작됩니다. 오른쪽 위 **샘플 맵**을 누르면 완성된 예제 도시가 열립니다.
2. 아래 **1× / 2× / 4×** 로 속도를 바꾸고, 오른쪽 **교통 현황**에서 정체 지수(0~100, 낮을수록 원활)를 봅니다.
3. 막히는 곳이 보이면 **일시정지**하고 도로·표지를 고친 뒤 다시 흐름을 봅니다.

## 조작

| 하고 싶은 일 | 방법 |
|---|---|
| 도로 그리기 | **왕복 2차로 / 4차로** 버튼(또는 R, T)을 누르고 시작점에서 **왼쪽 버튼을 누른 채 끌어서** 끝점에서 놓기. 터치는 한 손가락 드래그. Esc·우클릭으로 취소 |
| 화면 이동 | **가운데 버튼(휠 누르기) 드래그**. 도구를 안 쓸 때는 왼쪽 드래그도 이동. 터치는 두 손가락 |
| 회전 · 확대 | 오른쪽 드래그 · 휠 |
| 구역 칠하기 | **주거 구역(H) / 직장 구역(O)** 을 누르고 도로 옆 빈 땅(도로에서 45m 안)을 드래그. 수요 막대(오른쪽 패널)가 높을수록 건물이 빨리 자랍니다. **구역 지우기(E)** 로 지웁니다 |
| 정지·양보 표지 | S / Y를 누르고 교차로에 가까운 도로 클릭. 같은 곳을 다시 클릭하면 치움 |
| 도로 넓히기 | **도로 넓히기(U)** 를 누르고 왕복 2차로를 클릭하면 4차로가 됩니다(교차로 사이 한 구간씩, 옆에 건물이 있으면 안 됩니다) |
| 철거 | X를 누르고 건물이나 도로 클릭 (외부로 이어지는 시작 도로는 철거할 수 없습니다) |
| 취소 / 다시 | Ctrl+Z / Ctrl+Y |
| 일시정지 | Space (정지 중에도 건설할 수 있습니다) |
| 디버그 표시 | D (FPS, 차선 ID, 차량 상태, 안전망·교착 횟수) |
| 저장 | 슬롯 저장·불러오기, 파일로 저장·열기. 1분마다 **자동 저장** 슬롯에도 저장됩니다 |

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 자동 테스트(화면 없이 시뮬레이션을 돌려 검증)
npm run build    # 배포용 빌드
npm run smoke    # 빌드한 화면을 실제 브라우저로 열어 점검 (npm run build 후, Playwright 필요)
```

`main` 브랜치에 병합되면 GitHub Pages로 자동 배포됩니다.

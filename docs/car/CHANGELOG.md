# 카 컴퍼니(가칭) 업데이트 이력

## 0.1.0 — 2026-11-20 (저장 형식 1) — 미배포(브랜치에만 있음)
### 추가
- 차 한 대의 한 바퀴: 신차 기획(차체 3종, 고객층 6, 동력 등급 3, 옵션, 개발 방향 10점, 예산·기간, 색) → 개발(설계·시험·결함) → 출시(가격·마케팅·색·휠) → 평론가 4명 리뷰와 신문 → 월 판매 → 가격·마케팅 조정 → 단종 → 다음 차
- 새 게임에서 회사 이름 입력, 3D 차고(곡면 차체 5종, 1970년대/현대 스타일), 회사 탭(재무·대출·직원·공장), 기록 탭(출시 사진)
- 저장 칸 3 + 매월 자동 저장 + 파일 내보내기·가져오기, 파산과 구제 금융(1회)
- 결함 경고(개발·출시 화면)와 출시 전 확인 창
### 확인한 것
- 자동 테스트 64개(car), 전체 689개 통과, 타입 검사 오류 0, 브라우저 점검 64항목(1366×1024, 1480×925, 400×800 가로 넘침 0, 콘솔 오류 0)
### 알려진 문제(미확인·미해결)
- 실제 아이패드·갤럭시 탭에서의 터치감·속도·저장 동작 미확인(헤드리스 브라우저로만 확인)
- 1971년 1월에 국내 시장 규모가 한 번에 약 3배로 뛴다(연 규모를 해마다 계단식으로 올리는 탓). 2단계 시작 때 고친다
- 고급 동력을 기준가에 팔면 대당 이익이 마이너스다(가격을 올려야 함). 의도인지 재검토 필요
- 화면의 "남은 결함 약 N개"는 ±15% 오차가 있어 14개로 보여도 실제 감점(15개 이상)이 날 수 있다
- 균형은 봇 측정 기준이며 사람이 한 플레이 느낌은 미확인. 보정 여유가 좁다(회수 7개월, 4점대 판매 56%)
- 페이스리프트·풀체인지, 직원 채용, 공장 증설, 연구, 시대 사건, 수출은 아직 없다(2~5단계)

### 알려진 문제(미확인·미해결)
- 봇 기준으로 목표에서 벗어난 값: 20년 차 공장 등급 4(목표 2~3)·현금 1,667억(목표 100~1,500억)으로 성장이 조금 빠르다. 30년 차 차 등급 3.8(목표 4.5~7): 평판을 올릴 수단이 부족해 본사가 2등급에 머무는 판이 많다(6단계 시상식에서 보완 예정)

- 픽업의 짐칸은 기본 각도를 돌려 보이게 했지만 다른 화면의 작은 그림에서는 잘 안 보일 수 있다. 스포츠카와 쿠페의 옆모습 아이콘이 비슷하다
- 브라우저 점검의 "몇 달 진행: 판매 발생" 항목이 드물게 실패한 적이 있다(점검이 매번 다른 시드로 돌기 때문으로 추정, 원인 미확인) (이번 최종 검사 2회는 모두 통과)
- 실제 아이패드·갤럭시 탭에서의 속도와 터치 손맛 미확인
- 수출, 경쟁사 6곳의 제대로 된 규칙, 시장 지도는 아직 없다(5단계)

- 모양 고르기: 옆모습 후보 3개 + 얼굴 후보 3개(그림과 한 줄 설명). 시대 스타일 4종(1970·1990·2010·2020년대)

### 바뀜
- 신차 기획·출시 화면: 아래에 붙어 있던 버튼을 없애고 내용 맨 끝의 버튼 줄로 옮김(마지막 단계에 [개발 시작], 출시 화면 끝에 요약과 [출시하기])
- 시장 규모가 해마다 계단식으로 뛰던 것을 달마다 매끄럽게 변하도록 수정(0.1.0의 "1971년 1월 3배 점프" 해결)

- 균형 수치: 페이스리프트 수명 되돌림 60%(늦으면 80%), 디자인 상승 한도 +10%, 인지도 +0.06, 시제차 비용 주당 5,800만원, 시장 규모 배수 2.1

### 알려진 문제(미확인·미해결)
- **공장이 월 300대로 고정**이라 1970년대 후반부터 주문이 생산 한도의 2~10배로 넘친다. 그래서 페이스리프트를 써도 더 팔 수 없고(봇 기준 +2%), 가격을 올리면 돈이 지나치게 빨리 불어난다. 3단계(공장 증설·직원 채용)에서 고친다
- 실제 아이패드·갤럭시 탭에서의 속도, 핀치·끌기 손맛, 사파리에서 핀치 때 페이지가 확대되지 않는지 미확인(터치 입력을 흉내 낸 자동 확인만 함)
- 사무실: 직원이 8명 이상이면 기본 화면에서 사람이 작고(화면 높이의 약 8%) 일하는 구역 가장자리가 잘린다. 시험 단계에서는 차가 있는 곳까지 넣느라 멀리서 본다. 개발 탭 배치와 함께 3단계에서 검토
- 풀체인지 때 차대 변화 폭이 작아 "확 바뀐" 느낌이 약할 수 있다. 2010년대와 2020년대 스타일이 비슷하다
- 페이스리프트 개발 화면의 능력치는 지금 판매 중인 판의 값을 보여 준다(개발 중 미리보기 없음)
- 균형은 봇 측정 기준이며 사람이 한 플레이 느낌은 미확인. 결과가 양극단으로 갈린다(잘되면 수백억, 아니면 파산)
- 직원 채용, 공장 증설, 연구, 시대 사건, 수출은 아직 없다(3~5단계)

### 확인한 것
- 자동 테스트 64개(car), 전체 689개 통과, 타입 검사 오류 0, 브라우저 점검 64항목(1366×1024, 1480×925, 400×800 가로 넘침 0, 콘솔 오류 0)
### 알려진 문제(미확인·미해결)
- 실제 아이패드·갤럭시 탭에서의 터치감·속도·저장 동작 미확인(헤드리스 브라우저로만 확인)
- 1971년 1월에 국내 시장 규모가 한 번에 약 3배로 뛴다(연 규모를 해마다 계단식으로 올리는 탓). 2단계 시작 때 고친다
- 고급 동력을 기준가에 팔면 대당 이익이 마이너스다(가격을 올려야 함). 의도인지 재검토 필요
- 화면의 "남은 결함 약 N개"는 ±15% 오차가 있어 14개로 보여도 실제 감점(15개 이상)이 날 수 있다
- 균형은 봇 측정 기준이며 사람이 한 플레이 느낌은 미확인. 보정 여유가 좁다(회수 7개월, 4점대 판매 56%)
- 페이스리프트·풀체인지, 직원 채용, 공장 증설, 연구, 시대 사건, 수출은 아직 없다(2~5단계)

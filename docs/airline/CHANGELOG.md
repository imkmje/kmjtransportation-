버전 규칙: 교통 게임과 같다(n.n.n). 1.0.0은 "플레이 가능한 코어가 완성된 시점". 그 전은 0.n.n.

## 0.3.0 — 경영 깊이 1단계: 대출·매각·노후화·사건 대응 (2026-11-10, Asia/Seoul)
### 추가
- **대출**: 한도(기본 $20M + 보유 항공기 장부가의 50%) 안에서 $10M씩 빌리고 갚는다. 월 이율은 1.0% + 3.0% × (잔액 ÷ 한도)라 한도를 많이 쓸수록 비싸다
- **항공기 매각**: 장부가의 90%를 받는다(노선에 배정돼 있으면 자동으로 뺌, 확인 창 있음)
- **노후화**: 보유 1개월마다 운영비가 0.4% 늘어난다(최대 +60%). 기단 탭에 사용 개월과 정비비 증가율 표시
- **기종 2종 추가**: 에이티알 T-72(초단거리 터보프롭, 70석), 에어바츠 A3-80(초대형, 450석). 이제 5종
- **사건 대응**: 연료비 급등(연료 계약 $2.0M, 비용 상승 제거), 불황(마케팅 캠페인 $3.0M, 수요 감소 절반), 폭설(임시 편성 $1.0M, 운항 감소 절반). 알림 탭에서 누른다
- **계속하기**: 목표를 달성하거나 기간이 끝난 뒤 목표·기한 없는 자유 모드로 계속(파산은 여전히 있음)
### 변경
- 항공기 1대당 월 정비·보험 비용 $0.4M 추가(월 고정비 = 본사 $1.0M + 항공기 수 × $0.4M)
- 목표 이익 $100M(기존 유지), 월 고정비 계산 표시
### 균형 점검(전략 × 시드 20개 × 24개월, 측정값)
- 방치 20/20 파산, 보수적 승 0(중간 이익 66), 공격적 승 0(77), 대출형 승 13(101), 무모형 승 0(60), 무작위 파산 3·승 0
- 처음에는 대출형이 20/20 승리(14개월)라 위험이 없었다 → 이율 가산 방식과 항공기당 비용을 넣어 조정
### 알려진 문제 (미확인 포함)
- 파산 위험은 아직 작다(좋은 전략은 파산하지 않고, 무모한 확장은 파산 대신 이익이 낮아짐). 사건 강화·경기 변동은 이후 검토
- 아이패드에서 직접 눌러 본 조작감과 재미는 확인하지 못했다
- 인구·소득·기종 제원은 예시값
### 저장 호환성
- 저장 형식 2. 형식 1 파일은 대출 0·목표 모드·항공기 나이 0으로 자동 변환(테스트로 확인)

## 0.2.0 — 화면 (2026-11-10, Asia/Seoul)
### 추가
- 지구 지도 화면(이동·확대, 도시·노선 누르기), 도시 12개, 노선 위를 나는 비행기 표시
- 도시 정보(시장 규모·성수기)와 월 수요가 큰 순서의 노선 열기 목록
- 노선 화면: 수요·좌석·탑승률·예상 수익, 운임 슬라이더, "자리를 꽉 채우는 운임" 맞추기, 항공기 배정(주간 왕복 횟수 조절)
- 기단(구매·배정 현황), 재무(현금·월별 이익 그래프·정산), 알림(사건) 탭
- 시작 화면, 저장·불러오기(자동 저장은 월말), 파산·승리·기간 종료 화면
- 주소: 교통 게임 주소 뒤에 `/air/`
### 변경
- 시작 항공기의 장부가를 구매가와 같게(0으로 보이던 것 수정)
### 알려진 문제 (미확인 포함)
- 아이패드에서 직접 눌러 본 조작감은 확인하지 못했다(소프트웨어 렌더로 화면과 동작만 점검)
- 도시 이름이 겹치는 곳(서울·제주·상하이)은 이름 위치를 조정했지만 확대하지 않으면 붐빈다
- 인구·소득·기종 제원은 예시값이다(공개 통계로 대조하지 않음)
- 재미(균형)는 자동 시뮬레이션으로만 점검했다

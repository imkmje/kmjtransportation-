## 2026-11-08 — 4단계(차간·교차로)

### 완료한 것
- **IDM**(앞차 간격 모델): 앞차·정지선·목적지를 장애물로 보고 가장 조심스러운 가속도를 쓴다. 3단계의 임시 간격 규칙 대체
- **교차로 통과 요청·허가**(src/sim/traffic.ts): 정지선 앞(30m + 제동거리) 안에서 줄 맨 앞 차량만 요청. 충돌 지점(교차·합류)이 겹치는 연결선끼리 동시 점유 금지. 이미 교차로 안에 있는 차량(뒤꽁무니가 아직 걸친 차량 포함)은 누구도 못 밀어낸다
- **우선순위**: 표지 없는 쪽 > 도로 등급(4차로 > 2차로) > 좌회전은 직진·우회전에 양보(1초 안에 도착한 경우) > 먼저 요청한 차 > 차량 ID
- **허가 유지**: 한 번 허가받은 차량은 교차로에 들어가기 전까지 보호(우선순위 역전 방지). 설계서에 없던 보강
- **출구 공간 점검**: 나갈 차선 맨 앞 차량의 뒤꽁무니와 차 한 대 + 안전 간격(6.5m) 이상 떨어져야 진입
- **정지·양보 표지**: 도구(S, Y), 3D 모양, 저장 형식 2(구형 1 파일 자동 변환). 정지 = 완전히 선 뒤 1.0초 대기, 양보 = 정지선에서 20km/h로 미리 부드럽게 감속. 표지 쪽은 표지 없는 쪽에 양보
- **차선 변경**(MOBIL 단순화): 이득 > 0.2m/s², 정중도 0.2, 우측 선호 0.1, 안전 감속 4.0 이하, 쿨다운 5초, 2초 동안 두 차선 점유(옆으로 미끄러지는 표시), 정지선 앞 30m 금지, 차선 진입 직후(차 길이 + 10m) 금지
- **교착 탐지·해소**: 5초마다 "누가 누구를 기다리는지" 순환 탐지, 순환이 5분 지속되면 1단계(가장 오래 기다린 차량에 출구 점검 면제 + 최우선), 30초 안에 안 풀리면 2단계(제거, 미완료 집계)
- **대기 이유 표시**: 정지 표지 / 양보 / 출구 공간 없음 / 앞차 / 회차 대기 / 정지
- **디버그 패널**: 충돌 점유, 차선 변경, 교착 해소·제거 횟수 추가
- **드래그로 도로 그리기**: 도로 도구에서 왼쪽 버튼을 누른 채 끌어서 그린다. 화면 이동은 가운데 버튼, 회전은 오른쪽 버튼. Esc·우클릭으로 그리는 중 취소. (이어 그리기는 없어짐)

### 설계서와 다른 부분 (설계서·rules.md는 승인 없이 고치지 않았다. 승인해 주시면 문서를 맞추겠다)

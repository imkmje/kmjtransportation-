# 게임 설계서

## 1. 개요
- 개인용, 혼자 플레이, 킬링타임 목적. 상용 출시는 고려하지 않는다(에셋과 명칭은 독자 제작).
- 핵심 재미 루프: 관찰 → 병목 발견 → 도로·신호 수정 → 흐름이 풀리는 것을 확인.
- 플레이 성향: 건설과 관찰 둘 다.
- 분위기: 밝은 로우폴리 "미니어처 도시". 상태(정지, 긴급, 사고)를 색으로 구분해 정체가 한눈에 읽히게 한다. 낮/밤과 비로 변주한다.
- 3D 표현이지만 시뮬레이션은 차선 그래프 위의 2D 로직이다.
- 곡선 도로 메시 생성이 번거로우므로 직선부터 시작한다.

## 2. 범위
- 포함: 도로·지형, 교차로·제어, 차량, 수요, 이벤트·변수, 분석·감상, 진행·보상. 대중교통과 주차는 후속 대규모 업데이트(3.x)로 하나씩 추가한다.
- 제외: 보행자(표시), 화물·산업 공급망, 서비스 건물, 재난, 에셋 에디터, 세금·건물 레벨업.
- 구역 시스템(1.1.0으로 앞당김, 사용자 결정 2026-11-09): 주거·직장은 건물을 하나씩 놓지 않고 **구역을 칠하면 수요 막대에 따라 다양한 모양의 건물이 자란다**(심시티식). 수요 막대(주거·직장)는 채택한다. 세금, 건물 레벨업, 서비스, 땅값은 채택하지 않는다.
- 외부 연결(1.1.0으로 앞당김): 새 도시는 지도 가장자리에서 들어오는 철거 불가 도로 하나로 시작한다(시티즈 스카이라인처럼). 외부 사람이 일하러 들어오고, 일부 시민은 외부로 출근한다. 통과 교통·배송은 1.3.0 이후.
- 건물 데이터에는 유형 분류, 규모, 설치 출처(플레이어/맵/자동 생성), 모양 값(variant), 주거 밀도가 있다.
- **의사결정 기준(2026-11-10)**: CS2를 벤치마킹한다(CLAUDE.md). 구역은 주거 저·중·고밀·상업·사무·산업(1.6.0), 학교는 직접 놓는 시설, 건물은 1×1~2×2칸(CS2는 최대 6×6), 사고·날씨 이벤트, 곡선·회전교차로·차선 방향 지정, 도로 6차로까지.

## 3. 게임 모드
| 모드 | 맵 | 규칙 | 목표 |
|---|---|---|---|
| 샌드박스 | 빈 지형(평지/언덕/강 선택) | 예산 무제한 또는 시작 자금 지정, 모든 도구 개방 | 없음(도시 평가 점수 참고 표시) |
| 정체 구출 | 제작된 고정 맵(JSON) | 예산·수정 횟수 중 맵마다 선택(둘 다 가능), 맵이 정한 도구 | 목표 CI 달성 |
| 도시 확장 챌린지 | 시드 기반 절차 생성 맵 | 수요 증가, 예산, 일차별 해금 | 오래 버티기 |
| 시드 퍼즐 | 시드 고정 맵 | 계획 단계 + 실행 1일, 고정 예산 | 평균 통행시간 개인 기록 |
승패와 점수는 rules.md 2~3항.

## 5. 데이터 모델 (1.0.0에서 확정)
- 노드: (x, y), 높이 z
- 도로 구간: 구조 유형(지면/다리/터널), 도로 종류, 속도 제한(기본값과 플레이어 설정값을 따로 보관)
- 차선: 상태(통행 가능/막힘/공사/폐쇄), 방향, 연결 정보
- 차종: 길이, 폭, 최고속도, 가속·제동, IDM 값, 우선순위
- 건물 노드: 유형(주거/상업/사무형 직장/산업형 직장/학교/이벤트 장소/외부 연결점/긴급 기지), 규모(소/중/대), 설치 출처(플레이어/맵/자동 생성), 삭제 가능 여부, 주차 수용량(3.0.0 예약)
- 이동: 목적, 출발·도착 건물, 발생 시각, 상태, 이동수단(3.0.0 예약, 현재 항상 차량), 차량 소유 ID(3.0.0 예약)
- 수요: 건물 유형·규모별 발생량 테이블, 귀환 풀
- 이벤트: 시작·종료 시각, 영향 대상(차선·구역)
- 시간: 시뮬레이션 시간, 시계 시간, 일차, 요일
- 맵: 고정 맵과 시드 생성 맵을 같은 포맷으로. 모드 설정(목표, 제한, 도구 목록) 포함
- 저장: 저장 형식 버전, 전체 시뮬 상태(차량, 풀, 예약, 이벤트, 난수 상태), 구형 변환 가능

## 7. 1.0.0 개발 단계
각 단계가 끝나면 확인 방법과 확인 포인트를 알리고 멈춘다.
0. 준비: Vite+TS+Three.js, Vitest, (가능하면) Playwright 스모크, src/config, 시드 난수, 고정 tick 루프 뼈대, 자동 배포. 확인: 배포 주소에서 빈 화면과 버전 표시
1. 3D 뼈대: 지면, 카메라 회전·이동·줌, 시계 표시, 배속 버튼(일시정지/1×/2×/4×), 탭 숨김 시 자동 일시정지
2. 도로 건설: 왕복 2·4차로 직선, 스냅·길이 표시, 기하 제약 미리보기(위반 시 빨간 표시), 교차점 자동 분할·교차로 생성, 철거, 실행 취소/다시 실행, 도로망 저장/불러오기
3. 차선 그래프·차량 주행: 차선 그래프, 테스트용 출발·도착 지점 도구, 승용차 경로 주행, 막다른 끝 회차, 디버그 오버레이 1차(차선 ID, 차량 상태, FPS, 차량 수)
4. 차간·교차로: IDM, 차선 변경, 비신호 교차로(우선순위, 타이브레이크, 충돌 지점 예약, 출구 공간 점검), 표지 도구, 대기 이유 표시, 교착 탐지·해소
5. 수요: 주거·사무형 직장 노드, 건물 연결 규칙, 출근·퇴근, 귀환 풀, 두 시계 연동, 기본 통계
6. 마감: 전체 상태 저장·자동 저장, 삭제 처리 규칙, 스냅샷·회귀 테스트, 성능 점검

완료 기준:
- 4지 교차로 시나리오(왕복 2차로, 왕복 4차로 각각)에 차량 1,000대: 충돌 지점 동시 점유 0, 안전망 개입 0, 교착 0, 전 차량 도착
- 4개 접근로 동시 도착 테스트: 타이브레이크로 정상 통과
- 막다른 길 테스트: 회차 후 도착
- 샘플 맵(구성은 Claude Code가 제안) 시계 1일 실행: 완료율 95% 이상, 안전망 0, 교착 0
- 결정론: 같은 시드 2회 실행 결과 일치, 저장·불러오기 후 이어서 실행한 결과가 끊김 없이 실행한 결과와 일치
- 성능: 차량 1,000대에서 60fps 목표(사용자 PC에서 체감 확인)
- 사용자 눈 확인: 도로 건설, 주행, 교차로 통과, 출퇴근 흐름
